# ESP32-S3 多媒体播放器验证清单

## 构建与凭据检查

```powershell
pio run -e 4d_systems_esp32s3_gen4_r8n16
python .\test\test_no_plaintext_credentials.py
```

## 实板验证

| 项目 | 操作 | 通过判据 |
|---|---|---|
| TFT | 上电 | 屏幕初始化、背光和 UI 正常显示。 |
| SD | 插入 FAT 格式 SD 卡 | 正常挂载并列出媒体文件。 |
| RAW | 打开 240×240 RGB565 文件 | 图片方向和颜色正确，无越界花屏。 |
| 文本 | 打开 UTF-8 中文 `.txt` | 可翻页、中文显示正常。 |
| 视频 | 打开符合格式的 `.vid` | 能播放并可退出，不影响后续 UI。 |
| 摇杆 | 上下左右、短按、长按 | 页面切换、选择、进入和退出操作正确。 |
| 网络 | 配置本机 `secrets.h` | NTP/天气可工作；无网络时本地媒体功能仍可使用。 |
| 投屏 | 进入 Stream 后运行推流工具 | TCP 8888 接收完整 RGB565 帧，画面连续刷新。 |

投屏带宽与帧率受 Wi-Fi 质量、CPU 和屏幕写入速度影响。验收时应记录使用的帧率和网络条件，不把演示条件下的性能写成固定吞吐承诺。
